Model assumptions & source reading

Clock edges & uncertainty

Launch FF edges are at its clock latency and T + latency. First capture FFs use T + latency; positive-level latches open at T/2 + latency and close at T + latency. Next-stage FFs use a 180-degree clock at 1.5T + latency, with previous hold edge 0.5T + latency. Clock latency includes buffer cells, clock wire and a signed offset. All values are picoseconds.

Setup margin = setup uncertainty + relative inter-cycle jitter. Hold margin = hold uncertainty + relative same-edge jitter. Jitter is a launch/capture difference bound, not RMS. Do not include it again inside residual uncertainty.

Illustrative cell library

At LVT / 1x, min/max delay: BUF 24/40, AND 30/60, OR 32/64, NAND 20/42, NOR 24/48, NOT 12/25 ps. Every cell is scaled independently by VT / sqrt(size): HVT 1.24, SVT 1.12, LVT 1, ULVT 0.82. Clock BUF uses a nominal 32 ps before scaling. Clock delay is deterministic here, not a clock OCV analysis.

Data minimum wire delay = 55% of maximum wire delay. OCV and noise apply after summing data cells and wire. Fanout adds 3/6 ps min/max per extra branch. Gates represent sensitized timing arcs with noncontrolling side inputs, not a Boolean simulator or a function-preserving ECO. Reordering cells does not change this additive model. There is no slew/load lookup, actual RC, clock CPPR, metastability, pulse-width or cycle re-pairing analysis.

Borrowing disabled imposes a zero-borrow budget, not an edge-triggered latch. Failed upstream checks make downstream values provisional. Educational model, not signoff STA.
